Engineering project

Edge AI video processing

Connecting models to real-time execution constraints.

C++ONNXRK3588 / DX-M1

My role   Model and inference-pipeline development.

What changes when a vision model has to run in a real system?

The system

The work connects RTSP video input, image preprocessing, accelerator inference, detection postprocessing, and video recording. The target environment combines an RK3588 single-board computer with the DEEPX DX-M1 accelerator.

My contribution

I worked on object-detection training and conversion, C++ inference integration, preprocessing and postprocessing, asynchronous execution, and buffer management. Debugging involved checking model input and output formats as well as the behavior of the surrounding pipeline.

Research relevance

This experience made latency, memory use, and data movement concrete considerations in my work. It informs how I approach the gap between a model’s offline evaluation and its behavior in a deployed system.
