Nano-MemGPT

Understanding memory-management failures in small language models.

Memory systemsTool useDistillation

My role   Research proposal and experimental scaffold.

Does an agent fail because it lacks knowledge, or because it does not retrieve the right memory?

The question

This work proposes separating answer-generation errors from failures in memory management, such as missing a retrieval call, making an unnecessary call, or stopping a chain of calls too early.

Experimental direction

The repository provides a scaffold for running Letta/MemGPT baselines, collecting teacher trajectories, diagnosing function-call behavior, and comparing full fine-tuning with LoRA. The intended evaluations include multi-session retrieval and document question answering.

Current scope

This is a research project in development. The page describes the proposal and experimental setup; it does not claim completed distillation results or verified gains.
